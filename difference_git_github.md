# La différence entre Git et GitHub

## 1. Git : système de gestion de versions

Git est un **logiciel de gestion de versions** qui permet de suivre les modifications apportées aux fichiers d'un projet.

### 1.1 Les principales fonctionnalités de Git
- **Suivi des modifications** : enregistre les changements effectués dans les fichiers.
- **Historique** : conserve les différentes versions du projet.
- **Commit** : permet d'enregistrer un état du projet.
- **Branches** : permettent de travailler sur différentes versions d'un projet.
- **Retour en arrière** : permet de restaurer une version précédente.

---

## 2. GitHub : plateforme de collaboration

GitHub est une **plateforme en ligne** qui héberge les projets utilisant Git et facilite le travail collaboratif.

### 2.1 Les principales fonctionnalités de GitHub
- **Hébergement** : stocke les projets sur Internet.
- **Partage** : permet de partager les projets avec d'autres utilisateurs.
- **Collaboration** : plusieurs personnes peuvent travailler sur le même projet.
- **Pull Request** : permet de proposer des modifications à un projet.
- **Issues** : permettent de signaler des problèmes et de suivre les tâches.

---

## 3. Les principales différences entre Git et GitHub

- **Git** : est un logiciel installé sur l'ordinateur pour gérer les versions d'un projet.
- **GitHub** : est une plateforme en ligne pour héberger et partager les projets Git.
